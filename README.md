# Superstore Sales Analysis — Tableau

**Created by Prathmesh Babasaheb Bhagwat**

A Tableau portfolio project exploring Superstore sales performance across regions, customer segments, time periods, and product rankings.

## Overview

This project uses a Superstore dataset to explore business performance and present sales data in Tableau. The analysis focuses on sales trends, regional performance, customer segments, and product performance.

## Business Questions

- How do sales trends change over time, including quarterly patterns?
- Which regions and customer segments contribute most to sales?
- Which products rank highest based on the selected metric?
- What patterns or opportunities can be identified from the dashboard?

## Tools

- Tableau — dashboards, visual analysis, calculated fields
- Superstore dataset — source data for sales analysis

- [ ] Clearly state the business problem and questions.
- [ ] Document dataset source and scope.
- [ ] Explain tools and workflow.
- [ ] Include screenshots or visual output.
- [ ] Add at least 4 specific, verified findings.
- [ ] Translate findings into actionable recommendations.
- [ ] Include setup/viewing instructions.
- [ ] Ensure all claims and metrics are reproducible.
